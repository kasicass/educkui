# stream example

Shows the streaming-data widget with a live producer, bounded buffer,
statistics and scroll controls.

```bash
./examples/stream/run.sh
```

Controls:

- `Space`: pause/resume
- `c`: clear buffer
- `s`: toggle statistics
- `Up` / `Down` / `PageUp` / `PageDown` / `Home` / `End`: scroll
- `Esc`: quit
