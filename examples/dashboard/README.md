# educkui dashboard showcase

Composes tabs, split pane, tree view, text input, pick list, gauge, sparkline,
bar chart, process monitor, log viewer and a dialog overlay.

Run it in a real terminal:

```bash
./examples/dashboard/run.sh
```

- `Tab` / arrow keys interact with the focused widget
- `Ctrl+D` toggles the About dialog
- `Esc` quits
