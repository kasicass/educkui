# form_builder example

Shows the form builder widget with text, password, checkbox, conditional
radio, select and multi-select fields, validation and submission.

```bash
./examples/form_builder/run.sh
```

Controls:

- `Tab` / `Shift+Tab`: move focus between components
- `Up` / `Down`: move between form fields and the submit button
- `Left` / `Right`: move the highlighted option (radio/select/multi_select)
- `Home` / `End`: move the text cursor in text fields
- `Space`: toggle checkbox/option or insert a space
- `Enter`: select option, move to the next field, or submit
- `Esc`: quit
